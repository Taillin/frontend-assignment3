## Brief Summary of the Work Process
In this assignment, I learned and applied core concepts of Responsive Web Design using CSS Media Queries and the Bootstrap 12-column grid system.

Key highlights of the work:
**Pure CSS Media Queries:** Configured responsive breakpoints for mobile, tablet, and desktop screens without any external libraries. Made text sizes scalable and built a dynamic layout using flexbox/grid.
**Bootstrap 5 Integration:** Used the Bootstrap 12-column grid (`container`, `row`, `col-*`) to build flexible column layouts, as well as an interactive responsive navbar with a collapsible hamburger menu.
**Combined Layout (Portfolio):** Built a complete portfolio page combining Bootstrap components with custom media queries to fine-tune spacing, typography, and element order on different devices.
**Code Quality:** Organized the project structure cleanly, ensured code readability, and verified that all pages run without errors.
